# Firebase Rules Notes

These are example patterns for the new job pipeline.

## Firestore

The frontend needs to read:
- `users/{uid}`
- `users/{uid}/jobs/{jobId}`

Example shape:

```txt
match /users/{uid} {
  allow read: if request.auth != null && request.auth.uid == uid;
  allow write: if false;

  match /jobs/{jobId} {
    allow read: if request.auth != null && request.auth.uid == uid;
    allow write: if false;
  }
}
```

Server-side writes happen through Firebase Admin in Netlify functions / worker.

## Storage

The frontend only needs to upload screenshot inputs.

Example shape:

```txt
match /users/{uid}/jobs/{jobId}/inputs/{fileName=**} {
  allow write: if request.auth != null && request.auth.uid == uid;
  allow read: if request.auth != null && request.auth.uid == uid;
}

match /artifacts/{uid}/{jobId}/{fileName=**} {
  allow read, write: if false;
}
```

Final artifact downloads are intended to go through signed URLs generated by the server.
